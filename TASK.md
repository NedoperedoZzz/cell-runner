# Техническое задание: Музыкальная игра "Ритм-рейд"

## Идея игры
Игрок управляет диджеем (или просто курсором-пластинкой), который готовится к главному сету на фестивале. Чтобы сет прошел идеально, нужно собрать как можно больше «Горячих треков» (нот/пластинок) и избегать «Сломанных колонок» (опасностей), которые портят звук и отнимают очки.

## Основная механика
Тип: **Собиратель с уклонением**.
- **Игрок** свободно перемещается по прямоугольному игровому полю (арене) с помощью клавиш управления (стрелки или WASD).
- На арене случайным образом появляются два типа объектов:
  1. **Полезные (Ноты / Пластинки):** При их сборе игрок получает +10 очков. Собранный объект исчезает и мгновенно появляется в новом случайном месте арены.
  2. **Опасные (Сломанные колонки / Красные крестики):** Статичные или хаотично движущиеся объекты. При столкновении с ними у игрока отнимается 15 очков (счет может уходить в минус) и он кратковременно мигает (визуальная индикация урона).

## Правила и цель
- **Цель:** Набрать максимальное количество очков до начала выступления.
- **Обязательное условие (таймер):** Раунд длится ровно **30 секунд** (или 60, на выбор разработчика). Таймер обратного отсчета отображается на экране. По истечении времени игра немедленно останавливается.
- **Начало:** Игра начинается по нажатию кнопки "Start" на стартовом экране.
- **Конец:** Когда таймер достигает 0, игра останавливается, и на экран выводится финальный счет и кнопка "Restart" для нового раунда.

## Обязательные требования к реализации
- Игра должна быть реализована в каталоге `site/` как браузерное приложение (HTML, CSS, JS).
- Можно использовать Vanilla JS (взаимодействие с DOM) или Canvas API. Сторонние игровые движки (Phaser, Unity и т.д.) запрещены.
- Интерфейс должен содержать: 
  - Игровое поле с явными границами.
  - Текущий счет.
  - Оставшееся время (таймер).
- Игрок не должен иметь возможности выйти за пределы игрового поля.

## Критерии приёмки
Автор задания (владелец ТЗ) будет проверять работу по следующим критериям:
1. **Запуск:** При открытии `site/index.html` отображается стартовый экран с кнопкой начала игры.
2. **Управление:** Персонаж корректно перемещается по экрану с помощью клавиатуры и не выходит за границы поля.
3. **Сбор:** При касании полезного объекта счет увеличивается, объект меняет позицию.
4. **Уклонение:** При касании опасности счет уменьшается (штраф отрабатывает корректно, нет бесконечного вычитания очков за одно касание).
5. **Таймер (обязательная особенность):** При старте игры запускается видимый таймер. Ровно при достижении 0 секунд управление блокируется, новые очки не начисляются.
6. **Окончание:** После остановки таймера появляется экран с результатами и работающей кнопкой "Restart".
